Engineering Architecture & Security

Structured design principles that elevate the application above legacy procedural code.

Domain / Service / Repository Layer
PSR-4 Autoloaded Core Architecture

Business rules are decoupled from presentation scripts into a clean, testable domain layer:

  • Value Objects: Election (window checking), Turnout (turnout arithmetic), Tally (winners & ties).
  • Services: VoteService (atomic ballot checking), AuthService (bcrypt + transparent SHA-1 upgrade), DemoDataSeeder.
  • Repositories: CategoryRepository, CandidateRepository, UserRepository, VoteRepository.
Security Hardening & Integrity
Auditable, Injection-Resistant Foundation

Comprehensive hardening protects voters and prevents ballot manipulation:

  • 1-Row-Per-Vote Model: Database UNIQUE(voter_id, category_id) prevents double-voting even under concurrent race conditions.
  • SQL Injection Neutralized: 100% parameterized PDO queries across all 23 controllers.
  • CSRF & XSS Defense: Cryptographic token verification on every POST; context-aware e() HTML escaping.
  • Active Ballot Protection: Deleting a candidate during active balloting is strictly rejected to preserve turnout integrity.
Bootstrap 3-to-5 Compatibility Bridge
Zero-Downtime Design System Upgrade

A custom CSS compatibility bridge in assets/css/style.css maps removed legacy classes (.panel, .form-group, .btn-block) to modern card tokens. This guaranteed zero broken layouts while upgrading to Bootstrap 5.3 + Bootswatch Zephyr.

Timezone Synchronization
Sub-Second Accurate Countdown Timers

Countdown timers calculate offsets from server-provided UTC epoch milliseconds, eliminating desynchronization when voters in different geographic time zones access elections configured in server local time.
