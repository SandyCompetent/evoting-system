# Security Policy

> **Disclaimer:** This e-Voting System is intended exclusively for **Portfolio and Demo** purposes. It is **not for commercial or production use**.

## Supported Versions

Because this is a portfolio showcase, only the latest code on the `main` branch is actively maintained and updated.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| others  | :x:                |

## Reporting a Vulnerability

Even though this is a demonstration project, security is taken seriously (incorporating CSRF validation, password hashing, and session fixation safeguards).

If you discover a security vulnerability within this project, please send an email to **sandy.competent@gmail.com** or open a private GitHub Security Advisory in this repository. 

Please do not disclose security-related issues publicly via standard GitHub issues until they have been reviewed and addressed.

### What to Expect

- We will acknowledge receipt of your vulnerability report as soon as possible.
- If the vulnerability is confirmed, a patch will be developed and pushed to the `main` branch.
- You will be notified once the fix is applied.
